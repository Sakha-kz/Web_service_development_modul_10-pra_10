# Отчёт и результаты работы: Модуль 10 (Практическая работа)

## 📌 Особенности реализации алгоритмов
1. **Различие между массивом и срезом:**
   - Массив `[3]float64{5, 10, 15}` имеет фиксированную длину и передается по значению (копируется).
   - Срез `sales := []Sale{...}` является динамическим представлением поверх базового массива с автоматическим масштабированием.
2. **Использование указателей:**
   В функции `ApplyDiscount(sale *Sale, discount float64)` параметр `sale` передан как указатель (`*Sale`). Это позволяет изменять значение поля `Price` непосредственно в исходном элементе среза `&sales[0]`.
3. **Группировка с помощью `map`:**
   Для суммирования количества проданных единиц каждого товара использован словарь `counts[s.Product] += s.Quantity`.
